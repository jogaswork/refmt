# НАСТРОЙКА

Открой:

app.js

Найди:

const BOT_USERNAME = "MTR_REF_BOT";

И замени на username своего Telegram-бота.

Например:

const BOT_USERNAME = "my_mtr_bot";

---

Также найди:

const SUPPORT_USERNAME = "MTR_SUPPORT";

И замени на username аккаунта поддержки.

Например:

const SUPPORT_USERNAME = "mtr_support";

---

# ВАЖНО

Username указывается БЕЗ @.

Правильно:

"mtr_support"

Неправильно:

"@mtr_support"

---

# Установка

Mini App должен находиться на HTTPS-сайте.

Например:

https://mtr-team.example/

После загрузки файлов получаешь:

https://mtr-team.example/

Этот адрес указываешь как Web App URL для Telegram-бота.

---

# Локальный тест

Можно открыть index.html обычным браузером.

В обычном браузере Telegram-пользователь будет недоступен,
поэтому приложение использует:

?user_id=123

Например:

index.html?user_id=123

# РЕАЛЬНАЯ СТАТИСТИКА

Для настоящей статистики нужно подключить backend.

Mini App отправляет:

tg.initData

на сервер.

Сервер должен проверить подпись Telegram.

После проверки сервер может вернуть:

{
    "refs": 25,
    "bonus": 1200,
    "level": 2
}

После этого данные будут отображаться
в Mini App.

---

# БЕЗОПАСНОСТЬ

Не доверяй:

tg.initDataUnsafe

на серверной стороне.

Для авторизации и получения данных
нужно проверять tg.initData
на backend по правилам Telegram Web Apps.
